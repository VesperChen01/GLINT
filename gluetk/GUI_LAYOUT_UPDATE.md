# GlueTK GUI 布局优化说明

## 📋 更新日期
2025-11-11

---

## ✨ 主要改动

### 1. **移除右侧 Results & Logs 栏位**
**原因**: 
- 右侧栏占用空间但使用频率低
- CSV 表格显示功能在实际使用中较少用到
- 为操作区腾出更多空间

**改动内容**:
- ✅ 移除右侧 `QTableWidget` 表格
- ✅ 移除右侧 Results & Logs 分组框
- ✅ 内容区现在占据除导航栏外的全部宽度

### 2. **新增底部日志区域**
**位置**: 整个 GUI 底部，固定高度

**功能**:
- 📋 Console Log: 显示所有操作日志和结果
- 进度条: 显示长时间操作的进度
- 高度固定: 80-120px，不占用过多空间

**特点**:
- 所有模块共享同一日志区域
- 自动滚动到最新日志
- 支持多行显示，方便查看详细输出

### 3. **Docking & Scoring 页面两栏布局**
**新布局结构**:
```
┌─────────────────────────────────────────────┐
│ 左栏                  │ 右栏                 │
├───────────────────────┼──────────────────────┤
│ 🔍 Pocket Detection   │ ⚙️ Vina Docking     │
│ & Visualization       │                      │
│                       │                      │
│ 📊 Quick Binding      │                      │
│ Score                 │                      │
├───────────────────────┴──────────────────────┤
│ 📊 Advanced Pocket Analysis (全宽)           │
│ ├─ 🔄 Comparison                             │
│ ├─ 🔗 PPI Interface                          │
│ ├─ 🔍 Interactions                           │
│ └─ ✨ G-motif                                │
└─────────────────────────────────────────────┘
```

**优势**:
- 相关功能分组更合理
- 充分利用横向空间
- 左栏：快速操作（口袋检测、评分）
- 右栏：对接配置（含 config 编辑）
- 底部：高级功能（全宽显示）

### 4. **Interaction Analysis 页面优化**
**保持现有网格布局**:
- Protein-Protein: 已经是两栏网格布局 ✅
- Protein-Ligand: 已经是两栏网格布局 ✅
- Atom Pair: 已经是两栏网格布局 ✅

**特点**:
- 表单式输入框紧凑排列
- 标签右对齐，输入框左对齐
- 按钮行水平排列

## 🎯 布局对比

### 之前的布局
```
┌──────┬────────────────┬─────────┐
│ Nav  │ Content        │ Results │
│ (固定)│ (可变)          │ (固定)   │
│      │                │ Table   │
│      │                │ Log     │
└──────┴────────────────┴─────────┘
```
- 内容区空间受限
- 右侧表格占用空间但使用率低
- 三栏布局显得拥挤

### 现在的布局
```
┌──────┬───────────────────────────┐
│ Nav  │ Content (全宽)             │
│ (固定)│                            │
│      │                            │
│      │                            │
├──────┴───────────────────────────┤
│ 📋 Console Log (底部，固定高度)  │
└────────────────────────────────────┘
```
- 内容区获得最大空间
- 两栏布局更清爽
- 日志统一在底部，不打扰操作

## 📐 尺寸规格

### 导航栏
- 最小宽度: 220px
- 最大宽度: 240px
- 自适应内容

### 内容区
- 弹性布局，占据所有剩余空间
- 两栏布局时左右各占 50%
- 单栏卡片时占据100%宽度

### 底部日志
- 最小高度: 80px
- 最大高度: 120px
- 自适应内容，但不超过最大值

### 卡片内部
- 外边距 (margin): 8px
- 内边距 (padding): 8px
- 元素间距 (spacing): 6-8px
- 输入框高度: 28-32px
- 按钮高度: 28-32px

## 🔧 技术实现

### 删除的组件
```python
# 已移除
self.table = QTableWidget()  # 右侧表格
self.right_widget = QWidget()  # 右侧容器

# 已移除的函数
fill_table_from_interactions()
fill_table_from_csv()
fill_table_from_gmotif_hits()
```

### 新增的组件
```python
# 底部日志区域
log_grp = QGroupBox("📋 Console Log")
self.log_edit = QTextEdit()  # 日志文本框 (80-120px)
self.progress_bar = QProgressBar()  # 进度条
```

### 布局权重分配
```python
# 主布局
main_layout.addLayout(content_row, 1)  # 内容区占大部分空间 (权重1)
main_layout.addWidget(log_grp, 0)      # 日志区固定高度 (权重0)

# 两栏布局 (Docking & Scoring)
two_col_layout.addLayout(left_col, 1)  # 左栏 50%
two_col_layout.addLayout(right_col, 1) # 右栏 50%
```

## 💡 使用建议

### Docking & Scoring 工作流
```
1. 左栏操作:
   - 检测口袋 (Detect Pockets)
   - 查看可视化结果
   - 快速评分 (Empirical/Vina)

2. 右栏操作:
   - 配置 Vina 对接
   - 编辑 config 文件
   - 运行对接任务

3. 底部查看:
   - 所有操作日志
   - 口袋检测结果统计
   - 对接评分输出

4. 高级分析:
   - 切换到 Advanced 标签页
   - 选择对比/界面/关联/G-motif 功能
```

### 查看分析结果
- **CSV 文件**: 所有分析自动保存为 CSV，可用外部工具查看
- **PyMOL 可视化**: 直接在 PyMOL 中查看 3D 结构
- **Console Log**: 底部日志显示摘要统计

## 🚀 未来优化建议

### 可能的进一步改进
1. **可折叠日志区**: 允许用户隐藏/显示日志区
2. **日志过滤**: 按模块或严重性过滤日志
3. **导出日志**: 保存日志到文件
4. **自定义布局**: 允许用户调整两栏比例
5. **快捷键**: 添加键盘快捷键提高效率

### 响应式设计
- 小屏幕 (<1400px): 自动切换为单栏布局
- 大屏幕 (>1920px): 三栏布局（中央分为左中右）
